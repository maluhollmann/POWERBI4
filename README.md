# POWERBI4
Esse mini-projeto foi criado para resolver questões de negócio da área Comercial. Utilizei o dataset da DSA e oque foi buscado resolver e mostrar nesse mini-projeto foi: 
• Montar uma Narrativa Inteligente;
• Principais Influenciadores de Vendas;
• Faixas de Vendas por Categorias e Pontos de Vendas;
• Performance dos Vendedores por Região;

Com isso eu aprendi mais sobre formatação do dashboard, como criar botões, também descobri mais gráficos e como usá-los.
